# Venturacom Auth

Base Angular 17 standalone para la experiencia de autenticación premium de Venturacom.

## Arquitectura

- `src/app/core`: modelos y utilidades compartidas.
- `src/app/shared/ui`: shell y componentes UI reutilizables.
- `src/app/features/auth`: pantallas de landing/login, registro y recuperación.

## Nota

El bloque exacto del design system solicitado no estaba incluido en el prompt, así que esta implementación usa un fallback coherente y minimalista basado en fondo oscuro + orb azul premium.
