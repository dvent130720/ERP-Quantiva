# Hola Mundo

Se creó una app mínima de Hola Mundo y se ejecuta con un servidor local.

## Ejecutar

```bash
cd ProyectoVenturacom
python3 -m http.server 4200
```

Abrir: http://localhost:4200

## Nota del entorno

Se intentó generar un proyecto Angular con `@angular/cli`, pero el entorno devuelve `403 Forbidden` al acceder al registro npm, por lo que no fue posible descargar dependencias externas.
