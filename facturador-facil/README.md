# Facturador Fácil (Angular)

Proyecto base en Angular para crear facturas sencillas.

## Funcionalidades
- Captura de datos del cliente.
- Agregar y quitar productos/servicios.
- Cálculo automático de subtotal, IVA y total.

## Ejecutar el proyecto
1. Instala dependencias:
   ```bash
   npm install
   ```
2. Levanta el entorno:
   ```bash
   npm start
   ```
3. Abre `http://localhost:4200`.

## Nota
En este entorno la descarga de paquetes de npm puede estar restringida; si ocurre un error 403 al instalar, ejecútalo en una red con acceso al registry de npm.
